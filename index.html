Kode Google Apps Script (Copy & Paste ke Spreadsheet Anda)
  1. Buka Google Spreadsheet Anda → klik menu Extensions > Apps Script.
  2. Hapus kode lama, lalu paste kode di bawah ini & klik Deploy > New deployment (atau Manage deployments > Edit > New version jika memperbarui).
  3. Pilih Type: Web app, Execute as: Me, Who has access: Anyone → klik Deploy (Jangan klik tombol Run manual di editor karena Web App dipanggil otomatis dari aplikasi ini).
  4. Salin Web app URL yang muncul dan tempelkan pada kolom URL di atas.
