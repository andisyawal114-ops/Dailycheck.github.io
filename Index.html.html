Cara Pasang di Google Spreadsheet (1 Menit):
  1. Buka Google Spreadsheet baru → klik menu Ekstensi (Extensions) → Apps Script.
  2. Hapus kode bawaan, tempel (paste) kode di bawah ini, lalu klik ikon Simpan.
  3. Klik Terapkan (Deploy) → Kelola deployment → Edit → Versi baru (atau Deployment baru jenis Aplikasi Web).
  4. Setel Yang memiliki akses ke Siapa saja (Anyone) → klik Terapkan → salin URL Web App ke kolom di atas.
